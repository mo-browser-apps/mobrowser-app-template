# Hello World

A private MōBrowser application, generated by MoControl from the pinned 2.17.0 SDK.

Use Node 24, `npm ci`, and `npm run dev`. Publish a signed macOS arm64 DMG from
MoControl or the Release workflow on `main`. Choose a fresh semantic version for each
release; rerun the same GitHub run to recover a failed attempt. MoControl provisions
signing secrets and release-service access. Installers are public; repository visibility
is independent. If signing was skipped during creation, apply a signing profile first.

The release workflow uses the bundled MoControl signing CLI. Its temporary keychain is
removed on success, failure and interruption. No local signing-server login is needed.
